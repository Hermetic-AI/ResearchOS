多智能体大模型自动规划方法

Jensen et al. · ResearchOS 草稿 v0.9 · 2026-07

1  Introduction

大语言模型驱动的 Agent 在工具使用与网页导航等任务上展现出可观潜力，然而其在长程、多步任务上的规划能力仍然受限。ReAct 等交替式推理-行动框架在 GAIA 等基准上的成功率随任务深度迅速衰减……

3  Method

我们提出 PlanMem：在规划器（Planner）与执行器（Executor）之间引入可读写、可审计的规划记忆 𝒫，其更新遵循

𝒫t+1 = 𝒫t ∪ Δ(at, ot)  ·  at ~ π(· | 𝒫t, st)

Python 代码 → Algorithm2e 伪代码

              

                
def plan_step(mem, state):
    plan = planner.propose(mem, state)
    for act in plan:
        obs = executor.act(act)
        mem.update(act, obs)
        if obs.fail:
            break  # replan

                

                  
✓ algorithm2e · 预览

                  
\begin{algorithm}[H]
\SetAlgoLined
\KwIn{规划记忆 $\mathcal{P}$，状态 $s_t$}
$\pi \leftarrow$ Planner$(\mathcal{P}, s_t)$\;
\For{$a \in \pi$}{
  $o \leftarrow$ Executor$(a)$\;
  $\mathcal{P} \leftarrow \mathcal{P} \cup \Delta(a, o)$\;
  \If{$o.\mathrm{fail}$}{\textbf{break}\;}
}
\end{algorithm}
