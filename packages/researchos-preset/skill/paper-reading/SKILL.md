# Paper Reading Skill

## Goal

When reading an academic paper, produce structured notes covering three dimensions: Method, Innovation, and Limitations.

## Workflow

1. Extract metadata: title, authors, year, venue, DOI.
2. Read abstract and identify the core research question.
3. For each section, extract:
   - **Method**: What technique / architecture / algorithm is used?
   - **Innovation**: What is the novel contribution compared to prior work?
   - **Limitations**: What caveats, assumptions, or restrictions does the paper acknowledge?

4. Generate a structured note with the following sections:
   - Summary (3 sentences)
   - Method breakdown
   - Key innovations
   - Limitations and future work
   - Relevance to current project

## Tips

- Do not paraphrase the entire paper. Focus on actionable insights.
- If a figure or table is critical, describe its key message.
- Compare against the local literature database if similar papers exist.
