# ResearchOS 可用性整改清单

本清单只在功能经过真实命令或端到端流程验证后标记完成。外部服务未配置时，对应功能保持“待配置”，不得宣称可用。

## P0 基础可用性

- [x] 统一启动与诊断：新增 `bun run researchos:dev` 与 `bun run researchos:doctor`。
- [x] 后端错误可定位：UnknownError 已在前端解包为可读原因、关联 ID 与下一步操作。
- [x] 模块级端到端冒烟测试：`bun run researchos:smoke` 覆盖资产读取、ResearchOS 导航和文献导入入口的页面、HTTP、服务与临时项目数据链路。
- [ ] 依赖健康状态页：页面中展示 Python、Tectonic、翻译服务和学术 API 的配置状态。

## P1 核心科研链路

- [x] 文献管理：真实 PDF 上传、元数据/参考文献解析、入库、详情查看与 BibTeX 导出闭环已通过浏览器测试；多源检索和 Zotero 导入通过包测试。图谱入库归入下一项的图谱联动验收。
- [x] 资产中心核心资产：Skill、SubAgent、Command 与 Rules 的读写、刷新解析和页面回显已通过浏览器回归；新文件无需重启后端。
- [ ] MCP 配置：保存、连接测试、错误诊断与重启策略的独立验收。
- [x] 知识图谱核心闭环：项目 Markdown/LaTeX 扫描、`[[wikilink]]`/`\cite{}` 解析、本地 SQLite 图存储、画布显示，以及向量不可用时 FTS 降级的 Graph RAG 已通过包测试和浏览器回归。
- [ ] LaTeX 与写作：依赖检测、诊断跳转、引用插入和编译预览闭环。

## P2 扩展能力

- [ ] 数据分析与绘图：CSV 上传、Python 执行、日志、产物与导出闭环。
- [ ] 翻译：服务自检、分段重试、摘要翻译与双语归档。
- [ ] 代码复现：受控执行、环境日志、指标提取与结果比对。

## P3 产品治理

- [ ] 功能状态页：区分可用、实验性、待配置和未实现。
- [ ] 原型逐页验收：布局、空状态、错误状态和核心操作与设计稿一致。
  - [ ] 全局工作台：补齐原型中的可折叠右侧上下文面板、底部运行状态栏、跨模块 Agent Dock 与状态分级。
  - [ ] 文献页：完成与原型一致的分类树 / 列表 / 详情三栏信息密度，以及导入、解析、引用、翻译的可见进度和恢复操作。
  - [ ] 图谱页：补齐后端健康/索引状态、关系线型图例、时间和关系筛选、节点来源跳转与带引文的 RAG 结果面板。
  - [ ] LaTeX / 数据 / 绘图 / 复现：逐页验证主操作、空状态、依赖未配置状态、日志与产物跳转，不以静态页面作为完成条件。
  - [ ] 资产中心：补齐 MCP 持久化、连接/断开/OAuth、预置模板、工具数和插件 Hook 可视化。
  - [ ] 文案和编码：清理页面中出现的 `鈥?` 等乱码字符串，统一为中文研究工作台文案和可执行的错误恢复提示。
