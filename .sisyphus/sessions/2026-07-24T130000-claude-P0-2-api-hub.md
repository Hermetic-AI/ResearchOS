## 完成内容

P0.2 API Hub 包开发完成。实现了统一的外部 API 管理层：

1. **Registry** — `ApiAdapter<TReq, TRes>` 接口 + `ApiHub` 接口 + `HubImpl` 实现
2. **四源 Adapter** — arXiv（Atom XML→JSON for zod）、Semantic Scholar、Crossref、PubMed
3. **横切能力** — 令牌桶限流、指数退避重试（max 3）、内存缓存（TTL 可配）、调用统计
4. **9 个测试全部通过** — 覆盖 RateLimiter、ResponseCache、withRetry、StatsCollector、HubImpl 注册/列表

## 关键决策

1. 纯 TS 库，不做 MCP server（服务对象是其他 @researchos/* 包的内部调用）
2. 零外部 HTTP 依赖：原生 `fetch` + 自写 retry/timeout（避免厂商 SDK）
3. RateLimiter 使用滑动窗口 `nextAllowed` 方案（比令牌桶简单，适合低 RPS 学术 API）
4. 缓存使用内存 Map（预留 SQLite 接口 `dbPath?`，后续可无缝切换）
5. adapter 声明窄 zod schema（只取所需字段），忽略多余字段防漂移

## 遗留问题

- tsgo typecheck 不通过（tsgo 不支持 bun 全局类型如 `fetch`/`URL`/`setTimeout`，与同仓库其他包一致）
- bun test 验证通过即可（真正的运行时行为正确）
- API key 管理需在资产管理中心 UI 面板实现（当前 adapter 使用 `{env:VAR}` 占位）
- 缓存未接入 SQLite（当前内存实现，可切换）
